# Spectral upsampling tables

`hanatos_irradiance_xy_coeffs_250304.lut` and `irradiance_xy_tc.npy` are the copies already published in upstream spektrafilm. A separate redistribution license for this Hanatos coefficient table was not found. They are included so the default `hanatos2025` path runs. See the repository `LICENSING.md`.

`SPEKTRAFILM_SPECTRAL_LUT_DIR` replaces a file when that directory contains the same filename. It is not required. This package does not download the tables.
